ProjectConnection

A paginated project result set.

type ProjectConnection {
  nodes: [Project!]!
  totalCount: Int!
}

Fields

ProjectConnection.nodes ● [Project!]! non-null object

Projects in the current result page.

ProjectConnection.totalCount ● Int! non-null scalar

The total number of projects matching the query.

Example

{
  "nodes": [
    {
      "id": "project_01",
      "name": "Mobile Refresh",
      "status": "ACTIVE",
      "owner": {
        "id": "user_01",
        "name": "Avery Chen"
      },
      "updatedAt": "2026-09-05T10:15:00Z"
    }
  ]
}
